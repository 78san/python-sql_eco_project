project title - E-Commerce Data Analysis using SQL & Python

Short Description -
This project analyzes an e-commerce dataset using SQL and Python to extract insights such as customer distribution,
sales performance, order trends, and payment behavior. The results are visualized using charts to support business decision-making.

Techniques / Tools Used -
SQL (MySQL) → Data extraction, joins, aggregation, filtering
Python (Pandas, NumPy) → Data processing and analysis
Data Visualization → Matplotlib & Seaborn charts
Database Connection → MySQL Connector (Python)
EDA (Exploratory Data Analysis)


Project Purpose -
Understand customer behavior (city, state analysis)
Analyze sales and product category performance
Track order trends over time (year/month)
Evaluate payment methods (installments, etc.)
Help businesses take data-driven decisions

Types of Questions Solved -
What are the unique cities where customers are located?
How many orders were placed in 2017?
What is the total sales for each product category?
How many customers are there in each state?
What percentage of orders were paid in installments?
How many orders were placed each month in 2018?
What is the average number of products per order (city-wise)?
Which states have the highest number of customers?
What are the sales trends across different categories?
How does customer distribution vary by location?
